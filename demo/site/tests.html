The tests so far

What has been proven

Every phase ends with its tests passing, a dated finding with numbers, and a commit. So far the tests prove the simulator. Every number it reports must hold: where light lands, how bright it is, what the camera records, and the ground truth of every frame. The detector will later be scored against exactly that truth. The suite below ran when this site was built.

By area

Where the tests are

Each part of the simulator has its own test file, written as unit tests, property tests and fixed-seed regressions, with tolerances stated in millimetres or in relative brightness.
